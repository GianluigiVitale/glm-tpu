- Refutation (b): `tpu_inference/__init__.py` does env-var overrides, GCE-metadata HTTP, and a `/dev/accel*` glob — no jax/libtpu client init anywhere in that chain (`env_override.py`, `tpu_info.py` read in full).

The "bare SamplingParams import → re-entrant vllm.platforms ImportError" claim could not be verified without running vllm imports (declined: TPU host).
