## 6. GLM-5.1-specific vs GLM-5.2
PR handles **nothing** DSA-specific: no IndexShare (GLM-5.2 shares indexer every 4 layers), no `indexer_rope_interleave` (interleaved RoPE), no MTP; indexer fully disabled. Hardcoded GLM-5.1 assumptions: 20 q-heads/TP=4→5 per rank comment (d:142) vs GLM-5.2's 64 heads; `N_blocks=hidden/128=48` (hidden 6144 — same as 5.2, d:2846-2848); shared-expert down_proj `K_blocks=16` block-scale kernel bug note (d:70-73); `MAX_MODEL_LEN` default 4096 (d:63) — 1M ctx unaddressed; smoke-test goldens are GLM-5.1 outputs; FP8 KV-cache NaN under EP forced `kv-cache-dtype=auto` (d:65-68).
